1. 총칙

「오늘낚시」(이하 "앱")를 운영하는 오늘낚시 운영팀(이하 "운영자")은 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 이 방침으로 처리 기준을 알립니다.

앱은 기본적으로 회원가입 없이 기기가 만든 무작위 식별자로 이용하며, 이름·전화번호를 요구하지 않습니다. 구글·애플 로그인은 이용자가 선택할 때만 연결됩니다.

2. 수집하는 정보

  • 기기 식별자(앱이 만드는 무작위 ID): 첫 실행 때 생성, 기기와 서버에 저장 (필수)
  • 닉네임: 이용자가 입력, 기기와 서버 (선택)
  • 소셜 로그인 정보(구글·애플이 주는 계정 ID, 이름, 이메일): 로그인할 때, 서버 (선택)
  • 위치(위도·경도): 포인트 추가, 인증 촬영 때 현장 확인, 주변 편의시설 조회, 위치 보내기에 사용. 인증 조과의 촬영 위치와 출조 알림을 켠 포인트의 좌표는 서버에 저장되며 다른 이용자에게 보이지 않음 (선택)
  • 조과 기록·사진·영상·게시글·댓글, 즐겨찾기한 포인트 이름: 이용자가 올리거나 설정할 때, 기기 또는 서버 (선택)
  • 어종 판별·인증 검수용 사진: 판별·검수 후 외부 서비스에 보관하지 않음 (선택)
  • 푸시 알림 토큰과 알림 설정: 알림을 켤 때, 서버 (선택)
  • 초대 코드와 초대 관계, 약관 동의 기록(버전·시각·마케팅 수신 여부): 서버
  • 신고·차단·제재 기록, 서비스 이용 기록(출석·미션 진행): 서버
  • 복구 코드를 입력할 때의 IP 주소: 무차별 대입을 막기 위해 서버에 30일 보관

앱은 광고 ID, 단말기 고유번호, 연락처를 수집하지 않으며 광고·분석 SDK를 쓰지 않습니다.

3. 이용 목적

  • 내 글·기록·점수·뱃지를 구분하고 보여 주기 위해
  • 조황·수다·동출 게시판 운영과 질서 유지(신고·차단·제재)
  • 인증 조과의 현장성 확인과 부정 방지
  • 포인트 날씨·물때·주변 정보 제공
  • 축하·댓글·출조 알림 등 이용자가 켠 알림 전송
  • 이벤트 운영과 보상 지급

수집한 정보를 광고·마케팅 목적으로 제3자에게 팔거나 제공하지 않습니다.

4. 보유 기간과 파기

  • 기기 안 정보: 앱 삭제 또는 설정의 「모두 지우기」 때까지
  • 서버의 게시물·기록·알림 설정: 이용자가 지우거나 탈퇴할 때까지 (백업 사본은 30일 안에 삭제)
  • 기기 식별자·닉네임·로그인 정보: 탈퇴하면 즉시 삭제
  • 신고·제재·동의 기록: 분쟁 대응과 반복 위반 방지를 위해 탈퇴 후 1년 보관 뒤 삭제
  • 복구 코드 입력 IP: 30일 뒤 자동 삭제
  • 어종 판별 사진, 날씨 조회 좌표: 보관하지 않음

5. 외부 전송과 처리 위탁

앱 기능을 위해 아래 외부 서비스에 최소한의 정보를 보냅니다.

  • Open-Meteo(독일): 포인트 좌표 - 날씨·파고·조위 예보
  • 공공데이터포털·국립해양조사원(한국): 관측소 코드와 날짜 - 조석 예보
  • OpenStreetMap Overpass(국외 미러): 포인트 좌표 - 주변 편의시설
  • Anthropic(미국): 어종 판별·인증 검수용 사진 - 학습에 쓰이지 않음
  • Expo(미국): 푸시 알림 토큰과 알림 문구 - 알림 전송(구글·애플 알림 서버를 거침)
  • 구글·애플: 소셜 로그인 인증
  • OpenStreetMap(지도 타일), jsDelivr·unpkg(글꼴·지도 파일): 화면을 불러올 때 접속 IP가 전달됨
  • 쿠팡·네이버 쇼핑: 이용자가 쇼핑 버튼을 누를 때만 검색어가 그 쇼핑몰로 넘어감. 이동한 뒤에는 그 쇼핑몰의 방침이 적용됨
  • 카카오맵·네이버 지도·메신저: 이용자가 길찾기나 위치 보내기를 누를 때만 장소 이름과 좌표가 그 앱으로 넘어감
  • 서버 호스팅: Amazon Web Services Lightsail(대한민국 서울) - 서버 운영(처리 위탁)

법령에 따른 수사기관의 정당한 요구가 있을 때는 그 범위 안에서 제공할 수 있습니다.

6. 이용자의 권리

  • 닉네임 변경: 설정
  • 내 글·기록 삭제: 글 화면의 「지우기」
  • 기기 안 정보 전부 삭제: 설정 → 모두 지우기
  • 서버의 내 정보 전부 삭제: 설정 → 계정 → 탈퇴 (게스트는 설정에 표시된 기기 식별자를 적어 문의)
  • 권한 철회: 기기 설정 → 앱 → 권한
  • 열람·정정·처리정지 요청: 문의처로 요청, 10일 안에 답변

7. 앱 권한

  • 위치(사용 중에만): 포인트 추가, 인증 촬영 현장 확인, 주변 정보
  • 카메라: 인증 조과 촬영, 어종 판별
  • 사진 보관함: 일반 조과 사진·영상 선택
  • 알림: 축하·댓글·즐겨찾기 포인트 조황·출조 알림 (설정에서 끌 수 있음)

모두 선택 권한이며, 거부해도 해당 기능 외에는 앱을 그대로 쓸 수 있습니다. 백그라운드 위치 추적은 하지 않습니다.

8. 안전 조치·아동·변경·문의

앱과 서버 사이 통신은 HTTPS로 암호화하고, 서버 접근은 운영자로 제한하며, 데이터는 매일 백업합니다.

앱은 만 14세 미만을 대상으로 하지 않으며, 아동 정보가 수집된 것을 알게 되면 바로 지웁니다.

방침이 바뀌면 시행 7일 전에 앱 안에 알리고 다시 동의를 받습니다.

9. 이 홈페이지

이 홈페이지(onulfish.com)는 회원가입·로그인·입력 양식이 없고 쿠키나 방문 분석 도구를 쓰지 않습니다.

  • GitHub Pages(미국): 홈페이지를 보여 주는 호스팅. 접속할 때 IP 주소 등 접속 기록이 GitHub에 남을 수 있음
  • cdnjs·unpkg: 화면 효과와 아이콘 파일을 불러올 때 접속 IP가 전달됨
