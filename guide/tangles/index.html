채비 엉킴 줄이기

푸는 시간 말고 낚시하는 시간

줄 푸느라 낚시할 시간이 없었던 적 있죠? 오늘은 채비 엉킴 줄이는 법이에요.

핵심만 먼저

  • 엉키는 순간: 던질 때, 떨어질 때, 감을 때
  • 떨어질 때: 닿기 직전 살짝 잡기 — 채비가 쭉 펴져요
  • 베일은 손으로: 손으로 닫기: 꼬임이 줄어요 (손잡이로 닫기: 줄이 꼬여요 ✗)
  • 감을 때: 팽팽하게 — 느슨하면 엉켜요
  • 꼬임 줄이기: 바람 등지기, 도래 달기: 꼬임을 풀어 줘요
  • 엉켰을 때: 당기지 말기 — 천천히 풀어요

엉키는 순간

엉킴은 주로 세 번 생겨요. 던질 때, 물에 떨어질 때, 줄을 감을 때예요.

  • 던질 때
  • 떨어질 때
  • 감을 때

떨어질 때

채비가 물에 닿기 직전, 손가락으로 줄을 살짝 잡아 주세요. 채비가 쭉 펴져요.

  • 닿기 직전 살짝 잡기 — 채비가 쭉 펴져요

베일은 손으로

던진 뒤 베일은 손으로 닫아 주세요. 손잡이를 돌려서 닫으면 줄이 꼬이기 쉬워요.

  • 손잡이로 닫기: 줄이 꼬여요
  • 손으로 닫기: 꼬임이 줄어요

감을 때

줄을 감을 때는 팽팽하게 감아 주세요. 느슨하게 감기면 다음에 던질 때 엉켜요.

  • 팽팽하게 — 느슨하면 엉켜요

꼬임 줄이기

바람을 등지고 던지고, 도래를 달아 두면 줄 꼬임이 한결 줄어요.

  • 바람 등지기
  • 도래 달기: 꼬임을 풀어 줘요

엉켰을 때

엉켰을 때 세게 당기면 매듭처럼 더 단단해져요. 천천히 느슨하게 풀어 주세요.

  • 당기지 말기 — 천천히 풀어요

심하게 엉켰다면

너무 심하게 엉켰으면, 과감히 자르고 다시 묶는 게 오히려 빨라요.

  • 잘라서 다시 묶기 — 오히려 빨라요
던지기와 줄 감기 요령은, 오늘낚시 가이드에서 다시 볼 수 있어요.
