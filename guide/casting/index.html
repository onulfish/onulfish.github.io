캐스팅 기초

안전하게 던지는 법

낚시에서 가장 많이 하는 동작이 던지기예요. 오늘은 안전한 캐스팅 기초예요.

핵심만 먼저

  • 먼저 주변 확인: 뒤 확인 — 바늘 사고 조심 (뒤·옆에 사람이 없게)
  • 던지기 1: 줄 늘어뜨리기, 검지에 줄 걸기
  • 던지기 2: 베일 열기, 대 뒤로 올리기
  • 놓는 순간: 앞쪽 위에서 놓기 — 대가 비스듬히 위를 볼 때
  • 놓는 때가 어긋나면: 너무 일찍: 위로 높이 떠요, 너무 늦게: 발 앞에 떨어져요
  • 힘보다 부드럽게: 부드럽게: 더 멀리 가요 (힘껏 휘두르기: 엉키고 빗나가요 ✗)

먼저 주변 확인

던지기 전엔 꼭 뒤와 옆을 돌아봐요. 바늘이 사람에게 걸리면 크게 다쳐요.

  • 뒤 확인 — 바늘 사고 조심 (뒤·옆에 사람이 없게)

던지기 1

먼저 줄을 대 끝에서 한 뼘 정도 늘어뜨리고, 검지 끝에 줄을 걸어요.

  1. 줄 늘어뜨리기
  2. 검지에 줄 걸기

던지기 2

그다음 베일을 열고, 대를 머리 위 뒤쪽으로 천천히 들어 올려요.

  1. 베일 열기
  2. 대 뒤로 올리기

놓는 순간

앞으로 휘두르다가, 대가 앞쪽 비스듬히 위를 가리킬 때 검지를 놓아요.

  • 앞쪽 위에서 놓기 — 대가 비스듬히 위를 볼 때

놓는 때가 어긋나면

너무 일찍 놓으면 위로 높이 뜨고, 너무 늦으면 발 앞에 떨어져요.

  • 너무 일찍: 위로 높이 떠요
  • 너무 늦게: 발 앞에 떨어져요

힘보다 부드럽게

힘껏 휘두르기보다 부드럽게 던지는 게, 오히려 더 멀리 가는 경우가 많아요.

  • 힘껏 휘두르기: 엉키고 빗나가요
  • 부드럽게: 더 멀리 가요

던진 다음

채비가 물에 닿으면 베일을 닫고, 줄을 살짝 감아서 팽팽하게 해 줘요.

  1. 베일 닫기
  2. 줄 팽팽하게
