1. 총칙

「오늘캠핑」(이하 "앱")을 운영하는 오늘캠핑 운영팀(이하 "운영자")은 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 이 방침으로 처리 기준을 알립니다.

앱은 기본적으로 회원가입 없이 기기가 만든 무작위 식별자로 이용하며, 이름·전화번호를 요구하지 않습니다. 카카오·구글·애플·이메일 가입은 이용자가 선택할 때만 연결됩니다.

2. 수집하는 정보

  • 기기 식별자(앱이 만드는 무작위 ID): 첫 실행 때 생성, 기기와 서버에 저장 (필수)
  • 닉네임: 이용자가 입력, 기기와 서버 (선택)
  • 주로 하는 캠핑 형태: 이용자가 선택, 기기에만 저장 (선택)
  • 가입 정보(카카오·구글·애플이 주는 계정 ID, 닉네임 또는 이름, 이메일 / 이메일 가입은 이메일 주소): 가입·로그인할 때, 서버 (선택)
  • 이메일 인증 코드: 이메일로 가입할 때 10분 동안만 서버 메모리에 두고 지움
  • 프리미엄 구독 정보(구글 플레이 구매 확인 토큰, 상품, 만료일): 구독할 때, 서버 (선택) - 카드·계좌 등 결제 수단 정보는 받지 않음
  • 위치(위도·경도): 「내 위치로 보기」를 누를 때만 사용. 그 자리의 날씨를 받고 가까운 캠핑장을 찾는 데 쓰며 기기에만 저장 (선택)
  • 캠핑 일지: 서버에 요약(날짜·박수·캠핑장 이름과 좌표·시·도·자연환경·캠핑 형태·인원·별점·그날 날씨 요약·사진과 메모가 있는지 여부) 저장 - 미션 진행과 캠핑 가는 날 알림 (선택)
  • 일지 백업(프리미엄, 이용자가 켤 때만): 일지 사진(가로 1,280px 이하로 줄인 사본)·메모·전체 내용, 서버 (선택)
  • 현장 제보: 닉네임·붐빔 정도·상황 태그·한 줄 글·시각, 서버 - 다른 이용자에게 72시간 보임. 「지금 어때요?」 질문은 누가 언제 물었는지만 서버 (선택)
  • 같이 챙기기: 짐 목록 이름·항목과 체크·담당한 닉네임, 서버 - 코드를 아는 사람에게 보임 (선택)
  • 즐겨찾기 캠핑장: 기기와 서버 - 특보 알림·「지금 어때요?」 질문 받기 (선택)
  • 짐 체크리스트·짐 세트·고른 장소·내 몸 맞춤 점수 설정·예약 오픈 알림: 기기에만 저장
  • 서비스 이용 기록(출석, 캠핑장 보기·즐겨찾기·짐 다 챙김·캠핑 지수 확인 같은 미션 진행): 서버
  • 푸시 알림 토큰과 알림 설정: 알림을 켤 때, 서버 (선택)
  • 초대 코드와 초대 관계, 약관 동의 기록(버전·시각·마케팅 수신 여부), 제재 기록: 서버
  • 앱 오류 보고(오류 내용, 기기 종류·OS·앱 버전): 앱이 오류로 멈출 때, 서버 - 기기 식별자는 함께 보내지 않음
  • 복구 코드를 입력할 때의 IP 주소: 무차별 대입을 막기 위해 서버에 30일 보관

앱은 광고 ID, 단말기 고유번호, 연락처를 수집하지 않으며 광고·분석 SDK를 쓰지 않습니다.

3. 이용 목적

  • 내 기록·미션·레벨·뱃지를 구분하고 보여 주기 위해
  • 고른 장소·캠핑장의 날씨·미세먼지·특보로 캠핑 지수를 계산하기 위해
  • 다른 기기로 옮기거나 다시 설치했을 때 미션 진행을 이어 주기 위해
  • 이용자가 켠 알림 전송, 이벤트 운영과 보상 지급, 부정 이용 방지
  • 오류를 고치고 서비스를 안정적으로 운영하기 위해

수집한 정보를 광고·마케팅 목적으로 제3자에게 팔거나 제공하지 않습니다.

4. 보유 기간과 파기

  • 기기 안 정보(일지 사진·메모, 체크리스트, 짐 세트, 즐겨찾기): 앱 삭제 또는 설정의 「모두 지우기」 때까지
  • 일지 백업(사진·메모): 그 기록을 지우거나 탈퇴할 때까지 (백업 사본은 30일 안에 삭제)
  • 현장 제보: 지우거나 탈퇴할 때까지(72시간이 지나면 다른 이용자에게 보이지 않음) · 같이 챙기기 목록: 마지막으로 고친 뒤 30일
  • 서버의 일지 요약·이용 기록·알림 설정: 이용자가 지우거나 탈퇴할 때까지 (백업 사본은 30일 안에 삭제)
  • 기기 식별자·닉네임·로그인 정보: 탈퇴하면 즉시 삭제
  • 제재·동의 기록: 분쟁 대응과 반복 위반 방지를 위해 탈퇴 후 1년 보관 뒤 삭제
  • 앱 오류 보고: 최근 1,000건만 두고 오래된 것부터 삭제
  • 복구 코드 입력 IP: 30일 뒤 자동 삭제
  • 날씨 조회 좌표: 보관하지 않음

5. 외부 전송과 처리 위탁

앱 기능을 위해 아래 외부 서비스에 최소한의 정보를 보냅니다.

  • Open-Meteo(독일 등 유럽): 고른 장소·캠핑장·내 위치의 좌표와 날짜 - 날씨 예보와 지난 날씨(일지)
  • 공공데이터포털(한국 - 한국관광공사 고캠핑, 한국환경공단 에어코리아, 기상청): 운영자 서버가 캠핑장 목록·미세먼지 예보·기상특보를 받아 옴. 이용자 정보는 보내지 않음
  • Expo(미국): 푸시 알림 토큰과 알림 문구 - 알림 전송(구글·애플 알림 서버를 거침)
  • 카카오·구글·애플: 이용자가 고른 소셜 로그인 인증
  • 구글 플레이: 프리미엄 구독 결제와 결제 확인(결제 수단은 구글이 처리)
  • 네이버 메일(한국): 이메일 가입 인증 코드 발송 - 받는 이메일 주소와 코드
  • 지도 그림: 운영자 서버가 브이월드(국토교통부)·OpenStreetMap에서 받아 보내 줌 - 이용자 정보는 보내지 않음
  • 한국관광공사 고캠핑(캠핑장 사진), jsDelivr·unpkg(글꼴·지도 파일): 화면을 불러올 때 접속 IP가 전달됨
  • 쿠팡·네이버 쇼핑: 이용자가 쇼핑 버튼을 누를 때만 검색어가 그 쇼핑몰로 넘어감. 이동한 뒤에는 그 쇼핑몰의 방침이 적용됨
  • 캠핑장 홈페이지·예약 사이트·전화: 이용자가 버튼을 누를 때만 그곳으로 연결됨
  • 서버 호스팅: Amazon Web Services Lightsail(대한민국 서울) - 서버 운영(처리 위탁)

법령에 따른 수사기관의 정당한 요구가 있을 때는 그 범위 안에서 제공할 수 있습니다.

6. 이용자의 권리

  • 닉네임·캠핑 형태 변경: 설정
  • 일지 삭제: 일지 화면의 「기록 지우기」 (서버 요약과 백업 사진·메모도 함께 지워짐)
  • 현장 제보 삭제: 캠핑장 화면의 내 제보 휴지통
  • 기기 안 정보 전부 삭제: 설정 → 모두 지우기
  • 서버의 내 정보 전부 삭제: 설정 → 계정 → 탈퇴 (게스트는 설정에 표시된 문의 번호를 적어 문의)
  • 권한 철회: 기기 설정 → 앱 → 권한
  • 열람·정정·처리정지 요청: 문의처로 요청, 10일 안에 답변

7. 앱 권한

  • 위치(사용 중에만): 「내 위치로 보기」 - 그 자리 날씨와 가까운 캠핑장
  • 카메라·사진 보관함: 캠핑 일지에 사진 남기기
  • 알림: 이벤트·캠핑 날씨 알림 (설정에서 끌 수 있음)

모두 선택 권한이며, 거부해도 해당 기능 외에는 앱을 그대로 쓸 수 있습니다. 백그라운드 위치 추적은 하지 않습니다.

8. 안전 조치·아동·변경·문의

앱과 서버 사이 통신은 HTTPS로 암호화하고, 기기마다 발급한 비밀키로 요청을 서명하며, 서버 접근은 운영자로 제한하고, 데이터는 매일 백업합니다.

앱은 만 14세 미만을 대상으로 하지 않으며, 아동 정보가 수집된 것을 알게 되면 바로 지웁니다.

방침이 바뀌면 시행 7일 전에 앱 안에 알리고 다시 동의를 받습니다.

9. 이 홈페이지

이 홈페이지(onulfish.com/camp)는 회원가입·로그인·입력 양식이 없고, 쿠키나 방문 분석 도구를 쓰지 않습니다. 글꼴과 아이콘도 이 홈페이지 안에서 불러옵니다.

  • GitHub Pages(미국): 홈페이지를 보여 주는 호스팅. 접속할 때 IP 주소 등 접속 기록이 GitHub에 남을 수 있음
  • 베타 테스터 신청(/camp/beta.html): 신청 메일로 받은 Gmail 주소(과 적어 주신 폰 기종·캠핑 형태)는 Google Play 비공개 테스트 초대, 테스터 안내, 정식 출시 때 테스터 보상(뱃지·프리미엄) 지급에만 쓰고, 보상 지급을 마치면 지움. 메일은 네이버 메일(한국)로 받음
